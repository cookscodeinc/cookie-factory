## Cookie Factory setup

Start with the
[requirements]({{ "/manual/setup-guide/requirements" | relative_url }}), then
follow the
[installation guide]({{ "/manual/introduction/installation-guide" | relative_url }}).

Cookie Factory deliberately keeps runtime dependencies inside its image. The
host supplies Docker, Compose, Git, the source checkout, and the sibling GitHub
Docs template checkout.
