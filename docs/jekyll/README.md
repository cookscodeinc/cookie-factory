## Overview

Cookie Factory provides repeatable wrapper scripts for generating Cook's Code
projects. Its Docker Compose toolchain validates the wrappers against the
`feat-024` GitHub Docs Cookiecutter without requiring Python, Ruby, Bundler,
Jekyll, Node.js, or linting tools on the host.

## What it provides

- Wrapper scripts for GitHub Pages, Cookiecutter, Python, and Ansible projects
- A pinned VS Code Dev Container and Docker Compose development workflow
- Offline lint, pre-commit, upstream template, and integration test services
- A networked Jekyll stage for validating real remote-theme builds
- Generated Just the Docs documentation with a repeatable update path
